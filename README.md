
# Student Data Analysis using Python and Pandas

## Project Overview
This project analyzes student performance data using Python, Pandas, and Matplotlib. It helps understand students' marks and attendance through data analysis and visualization.

## Technologies Used
- Python
- Pandas
- Matplotlib
- CSV Dataset

## Features
- Load student data from a CSV file.
- Display the dataset.
- Check missing values.
- Remove duplicate records.
- Handle missing values.
- Generate summary statistics.
- Filter student records.
- Group and analyze data.
- Generate a performance graph.

## Project Files
- Student_Data_Analysis.py – Python source code.
- student_performance.csv – Student dataset.
- student_analysis_graph.png – Data visualization graph.

## How to Run
1. Install the required libraries:

   pip install pandas matplotlib

2. Run the Python script:

   python Student_Data_Analysis.py

## Output
The project displays the original dataset, cleaned data, missing values, summary statistics, filtered records, and grouped data. It also generates a graph.
